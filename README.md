# Residual Connections Explained

In this article, I explain the fundamentals of **residual connections** in deep learning, covering the core theory and intuition behind how they work.

To complement the theoretical explanation, I have also implemented a custom **ResNet-10 model from scratch using PyTorch** and trained it on the Fashion-MNIST dataset. This practical implementation demonstrates how residual connections can be incorporated into a neural network.

The article currently focuses on the basic theory and practical implementation rather than the mathematical derivation.

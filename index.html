Why Your Neural Network Gets Dumber With Every Layer — And the One-Line Fix That Changed AI

You added more layers. You expected a smarter model. You got a worse one. This is the story of the tiny shortcut that fixed deep learning—and how to build it from scratch.

The deeper, the dumber?

Here's a sentence that should be impossible in machine learning: making a neural network deeper can make it worse.

Not a little worse. Worse on the training data itself. The model isn't overfitting. It isn't starved of data. It is simply failing to learn.

If you've ever watched a loss curve flatline and wondered what you did wrong, you've already met the villain of this story.

The hero is hiding in plain sight. It looks like a typo in an equation:

y = F(x) + x

That tiny + x is the residual connection—the idea that made very deep neural networks trainable and quietly powers many of the models you use today.

In this article, I'll show you what residual connections are, what problem they solve, how they work, and how to implement them in PyTorch. We'll build a custom ResNet-10 from scratch and train it on Fashion-MNIST. Five epochs. 90.90% test accuracy.

I'm keeping the math light on purpose. Clear concepts first, working code second.

The paradox that broke deep learning

For complex, real-world tasks, we often need deeper, more sophisticated models. The intuition feels bulletproof: more layers, more capacity, better results.

Then reality steps in.

When networks get deep, performance doesn't always improve. Sometimes it gets worse—even though the model has more parameters and more power.

One major reason is the vanishing gradient problem: gradients become extremely small as they propagate backward through the network. The earliest layers—the ones learning the most basic features—barely update at all.

Residual Networks, or ResNets, solve this with residual connections, also called skip connections. They create more direct paths for gradients and make deep networks dramatically easier to optimize.

But to understand why a shortcut works, you first need to know what a gradient actually is. Don't worry—it's simpler than the name suggests.

Gradient, explained without the math headache

A gradient is a value that tells you how much the loss function changes when a weight changes. It tells the network how much to adjust a weight, and in which direction.

Small gradient, small weight update. Large gradient, large update—assuming the learning rate stays the same.

Think of it as a nudge. The gradient is the network's only clue about which way to move.

Now imagine that nudge has to travel through 50 layers before it reaches the weights that need it. That's where things fall apart.

The silent killer inside deep networks

Neural networks train through backpropagation. Gradients are calculated from the last layer back to the first, and the weights are updated based on those gradients.

In a shallow network, that's a short trip. In a deep network, it's a relay race through layer after layer.

At every step, gradients are multiplied by derivatives of activation functions and other factors. Multiply enough small numbers together and the result collapses toward zero.

By the time the gradient reaches the earlier layers, it's a faint echo. Those layers update very slowly—or effectively stop learning. That's the vanishing gradient problem.

It's like whispering a message down a very long line of people. By the time it reaches the front, the message is gone.

Here's the cruel irony: the deeper the network, the longer the relay, and the more chances the signal has to disappear. The extra layers add capacity, but the model can't use it.

The +x that saved deep learning

So how do you keep the signal alive? You give it a bypass.

In a standard neural network block, the input is transformed into an output:

y = F(x)

Here, F is the transformation—the stacked layers—x is the input, and y is the output.

A residual connection changes one thing:

y = F(x) + x

Adding the input back is what creates the skip connection. The signal no longer has to pass through every layer sequentially. It gets an identity path around the block.

During backpropagation, that identity path has a derivative of 1. Since multiplying by 1 doesn't shrink anything, gradients can flow straight through—even in a very deep network.

But there's a deeper shift in perspective. The block is no longer learning the full transformation. It's learning the residual—the difference between the input and the desired output.

If the best transformation is close to doing nothing, the block can simply push F(x) toward zero and pass the input through unchanged. That makes "do nothing" easy to learn.

And that, counterintuitively, is what makes deep networks so powerful.

Three blocks, one blueprint

Residual networks are built by stacking residual blocks. Each block contains a few layers plus a residual connection. Stack enough blocks and you get a deep residual network.

There are three main types: the basic block, the bottleneck block, and the pre-activation block.

The first two dominate classic ResNet architectures. The third powers pre-activation ResNets—and its design philosophy echoes through modern Transformers.

  1. Basic block: The simplest building block in the original ResNet. It uses two sequential 3 × 3 convolutional layers plus a residual connection. Input and output dimensions are usually equal. If they differ, a projection shortcut can match them.
  2. Bottleneck block: Three sequential convolutional layers plus a residual connection. The first is a 1 × 1 convolution for dimension reduction, the second is a 3 × 3 convolution, and the third is a 1 × 1 convolution that restores or expands the dimensions. The exact reduction depends on the architecture. ResNet-50, ResNet-101, and ResNet-152 all use bottleneck blocks.
  3. Pre-activation block: Normalization and activation are applied before the residual function F. Formally, the computation is:

xℓ+1​=F(ϕ(xℓ​))+xℓ​

Here, φ represents normalization and activation operations—such as Batch Normalization followed by ReLU—and F is the residual function.

This design reduces the number of non-identity mappings between residual blocks and allows an identity mapping directly from the input to the output. The result: better gradient propagation and easier training at extreme depth. Pre-activation ResNets have been shown to perform well with hundreds of layers.

Since GPT-2, Transformer blocks have commonly used pre-normalization, applying normalization before the attention and feed-forward sublayers. It's conceptually similar to pre-activation ResNets—not identical, but clearly related.

Build ResNet-10 from scratch

The architecture, decoded

Enough theory. Let's build something that trains.

We'll follow the ResNet-18 architecture, reduce the number of layers, and create our own ResNet-10—then train it from scratch on Fashion-MNIST.

ResNet-18 means Residual Network with 18 layers. It's a convolutional neural network (CNN) that uses residual connections to make deep training feasible.

ResNet-18 is built from BasicBlocks. The architecture has three parts:

  • An initial 3 × 3 convolutional layer.
  • Four residual stages, each containing two BasicBlocks.
  • One fully connected layer at the end for classification.

Each BasicBlock contains two convolutional layers, Batch Normalization, ReLU activation, and a shortcut connection.

Counting the layers (yes, all 18)

Let's add them up:

  1. Initial convolutional layer: 1 layer.
  2. Four residual stages: Each stage has two BasicBlocks, and each BasicBlock has two convolutional layers.
  3. Final fully connected layer: 1 layer.

For the residual stages, that's:

4×2×2=16

So the total number of layers is:

Total layers=1+16+1

Total layers=18​

That gives us one initial convolution, 16 convolutions spread across eight BasicBlocks, and one final fully connected layer.

For ResNet-10, we remove the last two residual stages. The total drops to 10 layers.

The batch normalization and activation details are all in the code below.

The PyTorch code

Here's the full implementation: the model, training loop, evaluation, confusion matrix, and sample predictions.

Read the BasicBlock class closely. That's where the residual connection lives.

import torch
import torch.nn as nn
import torch.optim as optim
import torchvision
import torchvision.transforms as transforms

import matplotlib.pyplot as plt
import numpy as np
import seaborn as sns

from torch.utils.data import DataLoader
from sklearn.metrics import confusion_matrix, classification_report


# ============================================================
# 1. DEVICE CONFIGURATION
# ============================================================

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
print("Using device:", device)


# ============================================================
# 2. FASHION-MNIST DATASET
# ============================================================

transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,))
])

train_dataset = torchvision.datasets.FashionMNIST(
    root="./data",
    train=True,
    download=True,
    transform=transform
)

test_dataset = torchvision.datasets.FashionMNIST(
    root="./data",
    train=False,
    download=True,
    transform=transform
)

train_loader = DataLoader(
    train_dataset,
    batch_size=128,
    shuffle=True,
    num_workers=0
)

test_loader = DataLoader(
    test_dataset,
    batch_size=128,
    shuffle=False,
    num_workers=0
)

class_names = [
    "T-shirt/top",
    "Trouser",
    "Pullover",
    "Dress",
    "Coat",
    "Sandal",
    "Shirt",
    "Sneaker",
    "Bag",
    "Ankle boot"
]


# ============================================================
# 3. RESNET-10 ARCHITECTURE
# ============================================================

class BasicBlock(nn.Module):
    expansion = 1

    def __init__(self, in_channels, out_channels, stride=1):
        super(BasicBlock, self).__init__()

        self.conv1 = nn.Conv2d(
            in_channels,
            out_channels,
            kernel_size=3,
            stride=stride,
            padding=1,
            bias=False
        )

        self.bn1 = nn.BatchNorm2d(out_channels)

        self.relu = nn.ReLU(inplace=True)

        self.conv2 = nn.Conv2d(
            out_channels,
            out_channels,
            kernel_size=3,
            stride=1,
            padding=1,
            bias=False
        )

        self.bn2 = nn.BatchNorm2d(out_channels)

        # Projection shortcut when dimensions change
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(
                    in_channels,
                    out_channels,
                    kernel_size=1,
                    stride=stride,
                    bias=False
                ),
                nn.BatchNorm2d(out_channels)
            )
        else:
            self.shortcut = nn.Identity()

    def forward(self, x):
        identity = self.shortcut(x)

        out = self.conv1(x)
        out = self.bn1(out)
        out = self.relu(out)

        out = self.conv2(out)
        out = self.bn2(out)

        out = out + identity
        out = self.relu(out)

        return out


class ResNet10(nn.Module):
    def __init__(self, num_classes=10):
        super(ResNet10, self).__init__()

        # Initial convolution: 1 channel for grayscale images
        self.conv1 = nn.Conv2d(
            1,
            64,
            kernel_size=3,
            stride=1,
            padding=1,
            bias=False
        )

        self.bn1 = nn.BatchNorm2d(64)
        self.relu = nn.ReLU(inplace=True)

        # Stage 1: two BasicBlocks convolutions = 4 convolutions
        self.layer1 = self.make_layer(
            64, 64, stride=1
        )

        # Stage 2: two BasicBlocks convolutions = 4 convolutions
        self.layer2 = self.make_layer(
            64, 128, stride=2
        )

        self.avgpool = nn.AdaptiveAvgPool2d((1, 1))

        self.fc = nn.Linear(128, num_classes)

    def make_layer(self, in_channels, out_channels, stride):
        return nn.Sequential(
            BasicBlock(in_channels, out_channels, stride),
            BasicBlock(out_channels, out_channels, stride=1)
        )

    def forward(self, x):
        x = self.conv1(x)
        x = self.bn1(x)
        x = self.relu(x)

        x = self.layer1(x)
        x = self.layer2(x)

        x = self.avgpool(x)
        x = torch.flatten(x, 1)

        x = self.fc(x)

        return x


# ============================================================
# 4. INITIALIZE MODEL, LOSS, AND OPTIMIZER
# ============================================================

model = ResNet10(num_classes=10).to(device)

criterion = nn.CrossEntropyLoss()

optimizer = optim.Adam(
    model.parameters(),
    lr=0.001
)

print(model)

total_parameters = sum(
    parameter.numel()
    for parameter in model.parameters()
    if parameter.requires_grad
)

print("Total trainable parameters:", total_parameters)


# ============================================================
# 5. TRAINING FUNCTION
# ============================================================

def train_one_epoch(model, loader, criterion, optimizer):
    model.train()

    running_loss = 0.0
    correct = 0
    total = 0

    for images, labels in loader:
        images = images.to(device)
        labels = labels.to(device)

        # Clear previous gradients
        optimizer.zero_grad()

        # Forward pass
        outputs = model(images)

        # Calculate loss
        loss = criterion(outputs, labels)

        # Backpropagation
        loss.backward()

        # Update weights
        optimizer.step()

        running_loss += loss.item() * images.size(0)

        _, predicted = torch.max(outputs, dim=1)

        total += labels.size(0)
        correct += (predicted == labels).sum().item()

    epoch_loss = running_loss / total
    epoch_accuracy = 100.0 * correct / total

    return epoch_loss, epoch_accuracy


# ============================================================
# 6. TESTING / EVALUATION FUNCTION
# ============================================================

def evaluate(model, loader, criterion):
    model.eval()

    running_loss = 0.0
    correct = 0
    total = 0

    all_labels = []
    all_predictions = []

    with torch.no_grad():
        for images, labels in loader:
            images = images.to(device)
            labels = labels.to(device)

            outputs = model(images)

            loss = criterion(outputs, labels)

            running_loss += loss.item() * images.size(0)

            _, predicted = torch.max(outputs, dim=1)

            total += labels.size(0)
            correct += (predicted == labels).sum().item()

            all_labels.extend(labels.cpu().numpy())
            all_predictions.extend(predicted.cpu().numpy())

    epoch_loss = running_loss / total
    epoch_accuracy = 100.0 * correct / total

    return (
        epoch_loss,
        epoch_accuracy,
        np.array(all_labels),
        np.array(all_predictions)
    )


# ============================================================
# 7. TRAINING LOOP
# ============================================================

num_epochs = 5

train_losses = []
test_losses = []

train_accuracies = []
test_accuracies = []

best_test_accuracy = 0.0

for epoch in range(num_epochs):

    train_loss, train_accuracy = train_one_epoch(
        model,
        train_loader,
        criterion,
        optimizer
    )

    test_loss, test_accuracy, _, _ = evaluate(
        model,
        test_loader,
        criterion
    )

    train_losses.append(train_loss)
    test_losses.append(test_loss)

    train_accuracies.append(train_accuracy)
    test_accuracies.append(test_accuracy)

    print(
        f"Epoch [{epoch + 1}/{num_epochs}] "
        f"| Train Loss: {train_loss:.4f} "
        f"| Test Loss: {test_loss:.4f} "
        f"| Train Accuracy: {train_accuracy:.2f}% "
        f"| Test Accuracy: {test_accuracy:.2f}%"
    )

    # Save the best model based on test accuracy
    if test_accuracy > best_test_accuracy:
        best_test_accuracy = test_accuracy

        torch.save(
            model.state_dict(),
            "best_resnet10_fashion_mnist.pth"
        )

I trained this exact model on Fashion-MNIST for just five epochs. That's all it took.

No exotic tricks. Just a clean residual architecture doing exactly what it was designed to do—learn through depth instead of fighting it.

How to push it even further

Five epochs is barely a warm-up. If you want stronger results, start here: apply data augmentation, increase training to 15–20 epochs, and add early stopping.

Those three changes are simple, practical, and likely to give you a meaningful boost.

The takeaway that changes how you build

Residual connections made it possible to build and train very deep neural networks more effectively. They improve gradient flow and address some of the hardest optimization problems that come with depth.

Their influence didn't stop at ResNets. Skip connections are now standard in Transformer architectures, where they help train the deep networks behind modern AI.

So the next time you stack another layer and your model refuses to learn, remember the fix hiding in plain sight:

y = F(x) + x

Give the gradient a shortcut. Let the network skip what it doesn't need to learn. Make "do nothing" easy.

Depth isn't about how many layers you can stack. It's about how many layers you can keep learning through.

That's the quiet idea that changed deep learning—and it's still shaping the models we build today.
